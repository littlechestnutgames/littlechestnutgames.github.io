Dockerized Development Environment

  • Tool Developer
  • Shell scripting
  • Containerization

When our chef and vagrant development environment wouldn't run on newer M1 architecture macs, I recreated our whole stack using Docker containers and orchestrated them using docker compose and zsh.

From within the command line interface, it is possible to bring up, put down, and rebuild any combination of containers within the project. Additionally many support commands were built in to aide the developer with common tasks, such as syncing databases across environments, easy terminal access inside containers, and ad-hoc queries on databases or redis instances.

What about the eggs?

  • Fullstack
  • API development
  • JavaScript

These eggs were developed as something fun and relevant to the to software engineering. I have setup a database to track egg prices at a local grocery store, a job to consume grocery store API data daily, and make use of an API endpoint to consume that data and display it as these eggs here.

The backend was written in NodeJS on HubSpot's serverless platform and the frontend was written in JavaScript, CSS, and HTML. Each egg holds the date that price was scraped, the price it was, and the color of the egg indicates whether the price increased from the last egg (red), remained the same price (white), or the went down (green).
